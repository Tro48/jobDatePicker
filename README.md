# jobDatePicker

Календарь сменного графика для Android: выбираешь график и дату первой смены —
календарь заполняется сам. Поверх графика вносятся ручные правки, считаются
часы и деньги, срабатывает будильник перед сменой.

В маркет не выкладывается, сборка для себя.

## Проверки

```bash
npm run test:domain     # тесты доменного слоя
npm run check:contrast  # контраст палитры по WCAG
```

Обе команды работают без Android SDK и без сборки приложения: доменный слой не
зависит от React Native, а Node 22 исполняет TypeScript напрямую.
