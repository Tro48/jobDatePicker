# Движок графиков

Главное требование: добавление нового графика должно быть простым. Поэтому
график — это **данные**, а не код. Движок умеет два способа раскладки, и все
поддерживаемые графики выражаются через них.

## Два генератора

**Цикл** (`kind: 'cycle'`) — массив дней фиксированной длины, который крутится
от даты первой смены. Индекс дня считается так:

```
индекс = floorMod(дата − дата_первой_смены, длина_цикла)
```

`floorMod`, а не остаток от деления: иначе даты до первой смены дают
отрицательный индекс, и календарь ломается при листании назад.

**Недельный** (`kind: 'weekly'`) — привязка к дням недели. Поле `weeks` — массив
недель: одна запись это обычная пятидневка, две — чередование «через субботу»,
и так далее. Дата первой смены здесь задаёт только то, с какой недели начинается
чередование; для одной недели она ни на что не влияет.

## Как добавить новый график

Одна запись в массиве `SCHEDULE_PRESETS` в `src/domain/presets.ts`. Ни движок,
ни экраны, ни сводка не меняются — список выбора графика строится из этого же
массива.

Цикл:

```ts
{
  id: '4-2',
  name: '4/2',
  description: 'Четыре смены по 12 часов, два выходных',
  pattern: { kind: 'cycle', slots: ['day12', 'day12', 'day12', 'day12', 'off', 'off'] },
}
```

Неделя с чередованием, «работа через субботу»:

```ts
{
  id: '5-2-every-other-saturday',
  name: '5/2, суббота через одну',
  description: 'Пятидневка, каждая вторая суббота рабочая',
  pattern: {
    kind: 'weekly',
    weeks: [
      { 1: 'work8', 2: 'work8', 3: 'work8', 4: 'work8', 5: 'work8', 6: 'work7', 7: 'off' },
      { 1: 'work8', 2: 'work8', 3: 'work8', 4: 'work8', 5: 'work8', 6: 'off',   7: 'off' },
    ],
  },
}
```

Если графику нужна смена, которой нет в справочнике, — сначала запись в
`DEFAULT_SHIFT_TYPES` в `src/domain/shifts.ts` (имя, буква-маркер, время,
перерыв, токен цвета), затем цвет под этот токен в обеих темах в
`src/theme/palette.ts`.

Забыть последний шаг не выйдет: `validatePreset` проверяет, что все id из
паттерна есть в справочнике, а `npm run check:contrast` — что у нового цвета
хватает контраста в светлой и тёмной теме. Тест
«все пресеты ссылаются только на существующие смены» гоняет проверку по всему
списку, так что опечатка в id ловится в тестах, а не в середине месяца на
телефоне.

## Когда двух генераторов не хватит

Третий вид графика добавляется новым вариантом union `SchedulePattern` в
`types.ts` и одной веткой в `resolvePlannedShiftId` в `engine.ts`. Остальной код
работает через `resolveDay` и про виды паттернов не знает. Вероятные кандидаты:

- привязка к производственному календарю (сокращённый день перед праздником,
  перенос выходных) — потребует справочника праздников по годам;
- бригадный график, где смена зависит от номера бригады;
- график с сезонной сменой времени начала.

## Ручные правки

Правка (`DayOverride`) кладётся поверх графика по конкретной дате и перекрывает
его целиком: другой тип смены, другое число часов, заметка. В `ResolvedDay`
остаётся поле `source` — `'schedule'` или `'override'`, — чтобы календарь мог
пометить изменённый день, а сводка посчитать, сколько дней в месяце пошло не по
плану.

`resolvePlannedShiftId` возвращает именно план, без правок. Это нужно для кнопки
«вернуть по графику» в карточке дня и для сравнения плана с фактом.

## Длительность смены

Считается из времени начала и конца, минус неоплачиваемый перерыв:

- `08:00 → 20:00` — 12 часов;
- `20:00 → 08:00` — конец меньше начала, значит переход через полночь, тоже 12 часов;
- `08:00 → 08:00` — ровно сутки, а не ноль;
- `09:00 → 18:00` с перерывом 60 минут — 8 часов.

Ночная смена целиком записывается на дату её начала. Делить часы между двумя
календарными днями приложение не будет: для месячной сводки это лишняя точность,
а расхождение возникает только на границе месяца и составляет одну смену.

## Даты и переход на летнее время

Даты внутри домена — строки `YYYY-MM-DD` и целые «эпохальные дни», без `Date` и
без часовых поясов. Прибавление суток через миллисекунды ломается в ночь
перевода часов, а график 2/2 обязан оставаться 2/2 в любую ночь. Тест на переход
через последнее воскресенье марта в наборе есть.
