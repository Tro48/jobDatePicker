# Экраны

Четыре вкладки внизу: **Календарь**, **Сводка**, **Будильник**, **Настройки**.
Карточка дня открывается модалкой поверх любой вкладки.

## Календарь

Главный экран. Месячная сетка, листается свайпом влево-вправо.

```
┌─────────────────────────────────┐
│  ‹    Сентябрь 2026        ›    │
│                                 │
│  Сегодня — ночная смена         │
│  20:00 – 08:00 · 12 ч           │
│                                 │
│  пн вт ср чт пт сб вс           │
│      1  2  3  4  5  6           │
│      Д  Д  В  В  Д  Д           │
│   7  8  9 10 11 12 13           │
│   В  В  Д  Д  В  В  Д           │
│  14 15 16 17 18 19 20           │
│   Д  В  В  П! Д  Д  В           │
│  …                              │
│                                 │
│  Д дневная   Н ночная           │
│  О отсыпной  В выходной         │
│  П подработка                   │
│                                 │
│  Сентябрь: 16 смен · 192 ч      │
└─────────────────────────────────┘
```

- Сетка всегда шесть строк по семь дней, хвосты соседних месяцев показываются
  приглушённо — так видно, как смены переходят через границу месяца.
- Ширина клетки округляется вниз. При дробной ширине семь клеток не помещались
  в строку, седьмая переносилась, и месяц смещался на колонку.
- В клетке — число, буква-маркер и заливка. Буква обязательна: смысл дня не
  передаётся одним лишь цветом.
- День с ручной правкой помечается точкой в углу (`!` на схеме), а не только
  другим оттенком.
- Сегодняшний день — рамка плюс жирное число.
- Тап по дню открывает карточку дня. Долгий тап — быстрое меню: «сделать
  выходным», «поставить подработку».
- Легенда показывает только те смены, которые в этом месяце реально есть.
- Внизу строка итогов по месяцу, чтобы не ходить в сводку ради двух чисел.

Пустого состояния нет: пока график не выбран, вместо сетки предложение выбрать
график с кнопкой в настройки.

## Карточка дня

```
┌─────────────────────────────────┐
│  Четверг, 17 сентября       [×] │
│                                 │
│  По графику: дневная            │
│  Сейчас: подработка             │
│  09:00 – 13:00 · 4 ч            │
│  «вышел за Сергея»              │
│                                 │
│  [ Изменить смену ]             │
│  [ Изменить часы  ]             │
│                                 │
│  Будильник                      │
│  06:30  Дневная смена           │
│  [ Добавить будильник на день ] │
│                                 │
│  [ Заметка        ]             │
│  [ Вернуть по графику ]         │
└─────────────────────────────────┘
```

«Вернуть по графику» показывается только когда правка есть, и удаляет её.
Строка «По графику» остаётся видимой всегда — чтобы было понятно, от чего
отличается факт.

**Отпуск и больничный** ставятся сразу на несколько дней. У таких смен в
справочнике стоит признак `multiDay`, и карточка дня показывает поле
«сколько дней подряд». Отсчёт идёт от начала уже проставленного отрезка, а не
от открытого дня: зайдя в середину отпуска и указав 14 дней, пользователь
задаёт длину, а не продлевает вдвое. Там же кнопка снять отпуск целиком.
Новый многодневный тип смены — «отгул», «командировка» — добавляется записью в
справочнике с этим признаком, экран менять не нужно.

**Будильник ставится отсюда же.** В карточке видно, что звонит в этот день, —
именно срабатывания, а не будильники: повторяющийся «по будням» тоже звонит
здесь, и это надо видеть до того, как заводить второй такой же. Кнопка ведёт на
экран правки с уже заполненными датой, временем за час до смены и её названием;
запись появляется в общем списке будильников после сохранения. Для прошедшего
дня кнопки нет — такой будильник погас бы сразу.

Заведённый отсюда будильник **всегда разовый и на этот день**: выбора повтора на
экране правки нет, он тут только сбивал бы с толку. Повторы настраиваются на
вкладке «Будильник».

**Выплата вносится здесь же.** Дата поступления — это и есть открытый день,
переспрашивать её незачем. Месяц, ЗА который платят, подставляется обратным
расчётом из правила выплат и остаётся правимым стрелками. Отдельного экрана
ввода выплаты нет: два способа делать одно и то же расходятся в поведении.

Карточка дня открывается модалкой без шапки, поэтому вертикальный отступ у неё
свой, с учётом выреза: иначе заголовок упирается в статус-бар. Переход по дате
защищён от повторного нажатия — двойной тап открывал два экрана подряд.

## Сводка

Отдельная вкладка. Месяцы листаются свайпом вбок и стрелками в шапке — тем же
пейджером, что и календарь. Стрелки остаются обязательными: свайп недоступен ни
с клавиатуры, ни через TalkBack, поэтому подменять их жестом нельзя. Шапка с
названием месяца стоит вне листалки и объявляет смену месяца скринридеру.

```
┌─────────────────────────────────┐
│  ‹   Сентябрь 2026   ›          │
│                                 │
│  Часы          Смены      Дней  │
│  192 ч         16         30    │
│                                 │
│  По типам смен                  │
│  Дневная      16 смен   192 ч   │
│  Подработка    1          4 ч   │
│  Выходной     14              — │
│                                 │
│  Изменено вручную: 2 дня        │
│                                 │
│  Деньги за месяц                │
│  Итого             95 000 ₽     │
│  За смену           4 688 ₽     │
│  За час               436 ₽     │
│  Аванс             30 000 ₽     │
│  Зарплата          45 000 ₽     │
│  Отпускные         20 000 ₽     │
│                                 │
│  [ Деньги по месяцам ]          │
│                                 │
│  Сравнение с июлем              │
│  Часы          192 ч → 84 ч     │
│  Смены        16 смен → 7 смен  │
└─────────────────────────────────┘
```

Ключевое правило: **выплата относится к месяцу, за который платят, а не к дате
поступления**. Аванс за сентябрь пришёл 27 августа — он в сентябрьской сводке.
Иначе август получил бы полторы выплаты, сентябрь половину, и ставка за час
поехала бы в обоих месяцах.

Ставка за час и за смену не задаётся в настройках, а выводится: деньги за месяц
делятся на отработанные часы и на число смен. Пока за месяц не внесено ни одной
выплаты, обе строки не показываются — приложение не выдумывает числа.

Отпускные и больничные идут отдельными строками и входят в сумму за месяц, но
**в ставки не входят**: они не заработаны часами. Месяц с двухнедельным отпуском
иначе показал бы ставку вдвое выше настоящей — по нескольким оставшимся сменам.

Сводка ничего не вводит и не правит: выплаты вносятся и удаляются в карточке
дня. Поэтому здесь нет ни кнопки ввода, ни удаления из списка.

Блок сравнения показывает **суммы обоих месяцев, а не разницу**: «192 ч → 84 ч».
Разница давала минус во всю зарплату прошлого месяца, стоило открыть месяц с
отпуском или незакрытый месяц — число верное, пользы ноль. Если за месяц выплат
нет, вместо суммы стоит прочерк: это честнее нуля.

### Деньги по месяцам

Открывается кнопкой из денежного блока сводки — отдельным экраном, а не ещё
одной карточкой в общей ленте.

```
┌─────────────────────────────────┐
│  ‹        2026        ›         │
│                                 │
│  Итого за год                   │
│  612 000 ₽                      │
│  Выплаты за 8 месяцев,          │
│  в среднем 76 500 ₽ в месяц     │
│                                 │
│  По месяцам                     │
│  Январь              75 000 ₽   │
│  ▓▓▓▓▓▓▓▓▓▓▓▓▓▓░░░░░░░░░░░░     │
│  Июль               127 000 ₽   │
│  ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓     │
│  из них отпускные 52 000 ₽      │
│  Сентябрь · сейчас   95 000 ₽   │
│  ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓░░░░░░░░░     │
└─────────────────────────────────┘
```

Полосы горизонтальные, а не столбики: при двенадцати столбиках подписи месяцев
не помещаются в ширину экрана и ломаются от увеличенного шрифта, а строкам это
безразлично. Полоса — только картинка, `aria-hidden`: то же число уже сказано
текстом справа. Текущий месяц помечен словом «сейчас» и жирным начертанием, а не
одним лишь цветом полосы.

Считается прямо по выплатам, без графика смен: месяц выплаты — тот, ЗА который
она пришла. Поэтому экран работает и когда график ещё не выбран.

Годы листаются свайпом и стрелками — тем же пейджером, что месяцы в сводке и
календаре. Окно строится вокруг года, с которым экран открыли: десять лет в
каждую сторону.

Для незакрытого месяца отдельным блоком показывается прогноз по ставке
последнего закрытого месяца, с явной подписью «прогноз». Ни в какие итоги он не
входит.

Виды выплат: аванс, зарплата, отпускные, больничный. У аванса и зарплаты есть
правило даты, у отпускных и больничного его нет — месяц подставляется по дате
поступления и правится стрелками.

## Будильник

```
┌─────────────────────────────────┐
│  Будильник                      │
│  Звонит даже на заблокированном │
│                                 │
│  Мои будильники                 │
│  06:30 · 18:30          [ вкл ] │
│  На смену                       │
│  По сменам: дневная, ночная     │
│  Через 8 ч 20 мин               │
│                                 │
│  07:15                 [ выкл ] │
│  Пн, Ср, Пт                     │
│  Выключен                       │
│                                 │
│  [ Добавить будильник ]         │
│  Поставлено в систему: 9        │
└─────────────────────────────────┘
```

Это обычный будильник: список, в котором сколько угодно записей, каждую можно
править, удалять, ставить на паузу и запускать обратно. Выключенный не
удаляется, а остаётся со всеми настройками — это пауза, а не потеря.

Строка списка показывает время, название, режим повтора и когда зазвонит
ближайший раз. Переключатель вынесен из нажимаемой области: вложенный, он давал
бы два разных действия на одной зоне нажатия, и скринридер читал бы это как одну
непонятную кнопку.

### Правка будильника

```
┌─────────────────────────────────┐
│  Когда звонить                  │
│           [ 06 ] : [ 30 ]       │
│         [ 00–11 ] [ 12–23 ]     │
│              ╭───────╮          │
│           11 │  12  │ 01        │
│         10   │  │    │   02     │
│         09   │  ●    │   03     │
│         08   │       │   04     │
│           07 ╰───────╯ 05       │
│                 06              │
│  Название      [ На смену     ] │
│  Включён                [ вкл ] │
│                                 │
│  Повтор                         │
│  ( ) Один раз                   │
│  ( ) По дням недели             │
│  (•) По сменам                  │
│  Дневная смена          [ вкл ] │
│  Ночная смена          [ выкл ] │
│                                 │
│  Сигнал                         │
│  Мелодия: Оксиген               │
│  [ Выбрать мелодию ]            │
│  Вибрация               [ вкл ] │
│  Отложить на, минут       10    │
│                                 │
│  [ Сохранить ]                  │
│  [ Удалить будильник ]          │
└─────────────────────────────────┘
```

Три режима повтора:

- **один раз** — дата выбирается месячной сеткой, прошедшие дни в ней
  выключены; зазвонит и погаснет сам, как в системных часах;
- **по дням недели** — семь переключателей плюс кнопки «Каждый день», «Будни»,
  «Выходные»; отмеченный день помечен не только цветом, но и закрашенным
  кружком против пустого;
- **по сменам** — звонит только в дни выбранных смен. Режим отвечает за дни, и
  ничего больше: время у будильника одно, как и в остальных режимах. График
  «день-ночь» — это два будильника: 06:30 с отмеченной дневной сменой и 18:30 с
  ночной.

Время выбирается циферблатом: сначала час, потом минуты — как в системных
часах. Системный диалог не используется, это ещё одна нативная зависимость ради
одного экрана; циферблат нарисован обычными `View` и работает без сторонних
библиотек.

Каждое число на циферблате — отдельная кнопка, поэтому время выбирается
нажатиями и доступно скринридеру и клавиатуре; протяжка по циферблату идёт
сверх этого, а не вместо. Часы разложены одним кольцом с переключателем
«00–11 / 12–23», а не двумя кольцами, как в Material: во внутреннее кольцо не
влезают зоны нажатия по 48 dp. На кольце минут подписаны пятиминутки, любая
другая минута набирается кнопками «минута назад» и «минута вперёд» или
протяжкой. Диаметр циферблата растёт вместе с системным размером шрифта.

Циферблат один и тот же во всех режимах повтора и стоит на одном и том же
месте — в карточке «Когда звонить», выше выбора повтора.

Если выбранный момент уже прошёл — например, сегодняшнее утро, — экран говорит
об этом прямо, а не сохраняет будильник, который погаснет в ту же секунду.

Мелодия выбирается из системного списка прямо на экране правки и сразу
проигрывается. Системный диалог выбора рингтона не используется: свой список
подчиняется теме приложения и размеру шрифта.

Форма держит черновик у себя и пишет в хранилище по кнопке «Сохранить» — иначе
каждая набранная цифра переставляла бы весь набор будильников в системе.

Если выбранный режим не даёт ни одного срабатывания (ни одного дня недели, ни
одной смены), экран говорит об этом прямым текстом, а не молча сохраняет
будильник, который никогда не зазвонит.

Пересчёт — при запуске приложения, при возврате в него, после перезагрузки
телефона, при переводе часов и при любой правке будильников, графика или
правок дней. Набор всегда ставится целиком, поэтому рассинхронизироваться
нечему. Синхронизация висит в корне навигации, а не на этом экране: вкладки
монтируются лениво, и приложение, открытое ради календаря, оставляло бы систему
со вчерашним набором.

На каждое недостающее разрешение — своя плашка с кнопкой в нужный экран
настроек: точные будильники, уведомления, экран поверх блокировки. Молча
деградировать до неточного будильника приложение не станет: проспать смену хуже,
чем увидеть предупреждение.

Отдельно сказано то, что кодом не лечится: оболочки Xiaomi, Huawei, Oppo, Vivo и
Samsung выгружают приложения из памяти, а принудительная остановка снимает все
будильники до следующего запуска.

Подробности реализации — в [docs/alarm.md](alarm.md).

## Настройки

- **График**: пресет из списка и дата первой смены. Под выбором — предпросмотр
  ближайших четырнадцати дней, чтобы не гадать, ту ли дату поставил.
- **Смены**: время начала и конца, неоплачиваемый перерыв, буква-маркер, цвет.
- **Выплаты**: правила аванса и зарплаты — день месяца, в каком месяце приходит
  относительно отработанного, что делать, если выпало на выходной.
- **Оформление**: системная тема / светлая / тёмная.
