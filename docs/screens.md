# Экраны

Четыре вкладки внизу: **Календарь**, **Сводка**, **Будильник**, **Настройки**.
Карточка дня открывается модалкой поверх любой вкладки.

## Календарь

Главный экран. Месячная сетка, листается свайпом влево-вправо.

```
┌─────────────────────────────────┐
│  ‹    Сентябрь 2026        ›    │
│                                 │
│  Сегодня — ночная смена         │
│  20:00 – 08:00 · 12 ч           │
│                                 │
│  пн вт ср чт пт сб вс           │
│      1  2  3  4  5  6           │
│      Д  Д  В  В  Д  Д           │
│   7  8  9 10 11 12 13           │
│   В  В  Д  Д  В  В  Д           │
│  14 15 16 17 18 19 20           │
│   Д  В  В  П! Д  Д  В           │
│  …                              │
│                                 │
│  Д дневная   Н ночная           │
│  О отсыпной  В выходной         │
│  П подработка                   │
│                                 │
│  Сентябрь: 16 смен · 192 ч      │
└─────────────────────────────────┘
```

- Сетка всегда шесть строк по семь дней, хвосты соседних месяцев показываются
  приглушённо — так видно, как смены переходят через границу месяца.
- Ширина клетки округляется вниз. При дробной ширине семь клеток не помещались
  в строку, седьмая переносилась, и месяц смещался на колонку.
- В клетке — число, буква-маркер и заливка. Буква обязательна: смысл дня не
  передаётся одним лишь цветом.
- День с ручной правкой помечается точкой в углу (`!` на схеме), а не только
  другим оттенком.
- Сегодняшний день — рамка плюс жирное число.
- Тап по дню открывает карточку дня. Долгий тап — быстрое меню: «сделать
  выходным», «поставить подработку».
- Легенда показывает только те смены, которые в этом месяце реально есть.
- Внизу строка итогов по месяцу, чтобы не ходить в сводку ради двух чисел.

Пустого состояния нет: пока график не выбран, вместо сетки предложение выбрать
график с кнопкой в настройки.

## Карточка дня

```
┌─────────────────────────────────┐
│  Четверг, 17 сентября       [×] │
│                                 │
│  По графику: дневная            │
│  Сейчас: подработка             │
│  09:00 – 13:00 · 4 ч            │
│  «вышел за Сергея»              │
│                                 │
│  [ Изменить смену ]             │
│  [ Изменить часы  ]             │
│  [ Заметка        ]             │
│  [ Вернуть по графику ]         │
└─────────────────────────────────┘
```

«Вернуть по графику» показывается только когда правка есть, и удаляет её.
Строка «По графику» остаётся видимой всегда — чтобы было понятно, от чего
отличается факт.

**Отпуск и больничный** ставятся сразу на несколько дней. У таких смен в
справочнике стоит признак `multiDay`, и карточка дня показывает поле
«сколько дней подряд». Отсчёт идёт от начала уже проставленного отрезка, а не
от открытого дня: зайдя в середину отпуска и указав 14 дней, пользователь
задаёт длину, а не продлевает вдвое. Там же кнопка снять отпуск целиком.
Новый многодневный тип смены — «отгул», «командировка» — добавляется записью в
справочнике с этим признаком, экран менять не нужно.

**Выплата вносится здесь же.** Дата поступления — это и есть открытый день,
переспрашивать её незачем. Месяц, ЗА который платят, подставляется обратным
расчётом из правила выплат и остаётся правимым стрелками. Отдельного экрана
ввода выплаты нет: два способа делать одно и то же расходятся в поведении.

Карточка дня открывается модалкой без шапки, поэтому вертикальный отступ у неё
свой, с учётом выреза: иначе заголовок упирается в статус-бар. Переход по дате
защищён от повторного нажатия — двойной тап открывал два экрана подряд.

## Сводка

Отдельная вкладка, месяц выбирается стрелками в шапке.

```
┌─────────────────────────────────┐
│  ‹   Сентябрь 2026   ›          │
│                                 │
│  Часы          Смены      Дней  │
│  192 ч         16         30    │
│                                 │
│  По типам смен                  │
│  Дневная      16 смен   192 ч   │
│  Подработка    1          4 ч   │
│  Выходной     14              — │
│                                 │
│  Изменено вручную: 2 дня        │
│                                 │
│  Деньги за месяц                │
│  Итого             95 000 ₽     │
│  За смену           4 688 ₽     │
│  За час               436 ₽     │
│  Аванс             30 000 ₽     │
│  Зарплата          45 000 ₽     │
│  Отпускные         20 000 ₽     │
│                                 │
│  К августу: +9 ч, +4 000 ₽      │
└─────────────────────────────────┘
```

Ключевое правило: **выплата относится к месяцу, за который платят, а не к дате
поступления**. Аванс за сентябрь пришёл 27 августа — он в сентябрьской сводке.
Иначе август получил бы полторы выплаты, сентябрь половину, и ставка за час
поехала бы в обоих месяцах.

Ставка за час и за смену не задаётся в настройках, а выводится: деньги за месяц
делятся на отработанные часы и на число смен. Пока за месяц не внесено ни одной
выплаты, обе строки не показываются — приложение не выдумывает числа.

Отпускные и больничные идут отдельными строками и входят в сумму за месяц, но
**в ставки не входят**: они не заработаны часами. Месяц с двухнедельным отпуском
иначе показал бы ставку вдвое выше настоящей — по нескольким оставшимся сменам.

Сводка ничего не вводит и не правит: выплаты вносятся и удаляются в карточке
дня. Поэтому здесь нет ни кнопки ввода, ни удаления из списка.

Деньги в блоке «К предыдущему месяцу» сравниваются, только когда выплаты внесены
за оба месяца. Открытый месяц с пустыми выплатами иначе показывал минус во всю
зарплату прошлого — это не разница, а отсутствие данных.

Для незакрытого месяца отдельным блоком показывается прогноз по ставке
последнего закрытого месяца, с явной подписью «прогноз». Ни в какие итоги он не
входит.

Виды выплат: аванс, зарплата, отпускные, больничный. У аванса и зарплаты есть
правило даты, у отпускных и больничного его нет — месяц подставляется по дате
поступления и правится стрелками.

## Будильник

```
┌─────────────────────────────────┐
│  Будильники                     │
│                                 │
│  Ближайший: завтра в 06:30      │
│  перед дневной сменой           │
│                                 │
│  Дневная смена       [ вкл  ]   │
│  за 1 ч 30 мин до начала        │
│  06:30 · пн–вс                  │
│                                 │
│  Ночная смена        [ выкл ]   │
│  за 2 ч до начала               │
│                                 │
│  Подработка          [ выкл ]   │
│                                 │
│  Мелодия, громкость, вибрация,  │
│  повтор — в настройках ниже     │
└─────────────────────────────────┘
```

Будильник настраивается на тип смены, а не на дату: «за полтора часа до дневной»
работает и после смены графика. Пересчёт — при открытии приложения, после
срабатывания, после перезагрузки телефона и при любой правке графика.

Подробности реализации — в [docs/alarm.md](alarm.md).

## Настройки

- **График**: пресет из списка и дата первой смены. Под выбором — предпросмотр
  ближайших четырнадцати дней, чтобы не гадать, ту ли дату поставил.
- **Смены**: время начала и конца, неоплачиваемый перерыв, буква-маркер, цвет.
- **Выплаты**: правила аванса и зарплаты — день месяца, в каком месяце приходит
  относительно отработанного, что делать, если выпало на выходной.
- **Оформление**: системная тема / светлая / тёмная.
