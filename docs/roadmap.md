# План работ

Этапы упорядочены так, чтобы приложение было полезным как можно раньше:
календарь с графиком работает уже после второго этапа, всё остальное
достраивается поверх.

## 0. Ядро — сделано

Доменный слой: даты, справочник смен, графики, движок раскладки, сводка за
месяц, даты выплат. Палитра обеих тем с проверкой контраста. 29 тестов и 60
проверок WCAG, зелёные, гоняются без Android SDK.

## 1. Каркас

- `create-expo-app`, TypeScript strict, expo-router, четыре вкладки-заглушки
- аккаунт Expo и первый dev build через EAS, установка APK на телефон
- MMKV, хранилище и репозитории, версия схемы
- провайдер темы, базовые компоненты интерфейса

Готово, когда на телефоне открывается приложение с четырьмя пустыми вкладками и
переживает перезапуск с сохранённой настройкой темы.

## 2. Календарь

- месячная сетка, листание свайпом, кнопка «сегодня»
- клетка дня: число, буква-маркер, заливка, метка ручной правки, озвучка
- экран выбора графика: пресет, дата первой смены, предпросмотр на 14 дней
- карточка дня и ручные правки
- легенда и строка итогов месяца

Готово, когда выбор «2/2 дневные» с датой первой смены заполняет календарь, а
подработка и незапланированный выходной вносятся в два касания.

## 3. Сводка

- вкладка сводки: часы, смены, дни, разбивка по типам смен
- ввод полученной суммы с привязкой к месяцу, за который платят
- правила аванса и зарплаты в настройках, подсказка о ближайшей выплате
- ставка за час и за смену из факта, сравнение с предыдущим месяцем
- прогноз для незакрытого месяца с явной подписью

## 4. Будильник

- нативный модуль на Kotlin, `setAlarmClock`, foreground service, full-screen intent
- config-плагин Expo с разрешениями
- перепланирование: старт приложения, срабатывание, `BOOT_COMPLETED`, смена часового пояса, правка графика
- экран настройки будильников по типам смен
- обработка отозванного `SCHEDULE_EXACT_ALARM` и подсказка про автозапуск на оболочках производителей

## 5. Доводка

- экспорт и импорт JSON
- проход с включённым TalkBack и с максимальным размером шрифта
- проверка на переходе через полночь, на границе месяца и в ночь перевода часов
- production-сборка APK, установка вместо dev build

## Что осознанно вне работы

- публикация в маркет — не планируется
- синхронизация между устройствами и любой сервер — данные живут только на телефоне
- iOS — задача про Android
- производственный календарь с праздниками и переносами — точка расширения
  описана в [движке графиков](schedule-engine.md), но в план не входит
- учёт сверхурочных по трудовому кодексу и налогов — приложение считает то, что
  внёс пользователь, и ничего не начисляет само
