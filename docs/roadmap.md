# План работ

Этапы упорядочены так, чтобы приложение было полезным как можно раньше:
календарь с графиком работает уже после второго этапа, всё остальное
достраивается поверх.

## 0. Ядро — сделано

Доменный слой: даты, справочник смен, графики, движок раскладки, сводка за
месяц, даты выплат. Палитра обеих тем с проверкой контраста. 29 тестов и 60
проверок WCAG, зелёные, гоняются без Android SDK.

## 1. Каркас — сделано, кроме сборки APK

- Expo SDK 57, TypeScript strict, expo-router, четыре вкладки
- MMKV, хранилище на zustand с версией схемы и миграцией
- провайдер темы на три состояния: системная, светлая, тёмная
- базовые компоненты: экран, текст, карточка, группа выбора
- `eas.json` с профилями development и production, оба собирают APK
- иконка приложения и заставка: рисуются скриптом `npm run icons`, шаблонные
  заменены; у заставки свои картинка и фон на светлую и тёмную тему

Проверено: `tsc --noEmit` чистый, `expo-doctor` проходит 21 проверку из 21,
JS-бандл под Android собирается (2.8 МБ байткода Hermes).

Осталось одно и требует твоего участия: `npx eas login` под бесплатным
аккаунтом Expo и первая сборка dev build. После установки APK на телефон этап
закрывается проверкой, что настройка темы переживает перезапуск приложения.

## 2. Календарь — написано, на устройстве не проверено

- месячная сетка на всю ширину экрана, листание свайпом и стрелками
- клетка дня: число, буква-маркер, заливка, точка на ручной правке, полная озвучка одной строкой
- экран выбора графика: список пресетов, дата первой смены нажатием по календарю, предпросмотр на 14 дней
- карточка дня: смена, часы, заметка, возврат к графику
- легенда только по сменам этого месяца и строка итогов

Проверено: 46 тестов домена, `tsc --noEmit` чистый, `expo-doctor` 21/21, бандл
собирается. Типизированные маршруты действительно проверяются — подстановка
несуществующего пути даёт ошибку компиляции.

Не проверено: приложение ни разу не запускалось. Всё поведение на экране —
листание, ввод, переходы, работа MMKV — держится на чтении кода.

## 3. Сводка — написано, на устройстве не проверено

- вкладка сводки: плитки часов, смен и выходных, разбивка по типам смен,
  листание месяцев свайпом и стрелками
- экран «Деньги по месяцам»: суммы за каждый месяц года горизонтальными
  полосами, годы листаются свайпом и стрелками, открывается кнопкой из
  денежного блока
- ввод выплаты прямо в карточке дня: месяц выводится обратным расчётом из правила
- удаление выплаты с подтверждением: оно меняет ставку задним числом
- настройки выплат с живым предпросмотром «аванс за сентябрь придёт 27 августа»
- ставка за час и за смену выводится из факта, сравнение с предыдущим месяцем
- прогноз для незакрытого месяца, подписанный источником ставки и исключённый из итогов

Проверено: 52 теста домена, `tsc --noEmit` чистый, `expo-doctor` 21/21, бандл
собирается. Разбор введённых руками дат и сумм покрыт тестами отдельно, включая
несуществующие даты вроде 31.02 — их `Date` молча превращает в соседние.

## 3.1. Правки по находкам с устройства — сделано

Первый прогон на телефоне дал шесть находок, все закрыты:

- **отпуск и больничный не спрашивали количество дней.** Справочник смен лежал
  в хранилище, и снимок из старой сборки перекрывал новый признак
  `multiDay`. Теперь справочник не персистится вообще, схема поднята до версии 2
- **заголовок карточки дня упирался в статус-бар** — у модалки нет шапки,
  добавлен собственный отступ по вырезу
- **двойной тап по дате открывал два экрана.** Переходы идут через
  `useGuardedPush`: замок снимается по возврату фокуса, со страховкой по таймеру
- **добавлены отпускные и больничный как виды выплат.** Правила даты у них нет,
  месяц подставляется по дате поступления
- **минус во всю зарплату прошлого месяца** в сравнении. Деньги сравниваются,
  только когда выплаты внесены за оба месяца
- **из сводки убран ввод денег.** Вкладка только показывает: сумма за месяц, за
  смену, за час, отпускные и больничные отдельными строками
- **сравнение с прошлым месяцем показывает суммы обоих месяцев**, а не разницу:
  минусов на экране больше нет, длинная подпись не наезжает на значение

Проверено: 69 тестов домена, `tsc --noEmit` чистый, 60 проверок контраста,
`expo-doctor` 21/21, бандл собирается. Всё это JS — пересборка APK не нужна.

## 4. Будильник — написан, нативная часть не собрана

Обычный будильник, а не настройка «за сколько до смены»: список произвольной
длины, правка, удаление, пауза, своя мелодия и вибрация у каждой записи.

- локальный Expo-модуль `modules/shift-alarm`: Kotlin, `setAlarmClock`,
  foreground service, full-screen intent, экран поверх блокировки с «Отключить»
  и «Отложить», список системных мелодий с прослушиванием
- разрешения в манифесте модуля, config-плагин не понадобился
- три режима повтора: один раз, по дням недели, по графику; в режиме графика у
  каждого типа смены своё время подъёма — «день-ночь» это одна запись с двумя
  временами
- разовый будильник гаснет сам, отзвонив
- планирование — чистая доменная функция `planAlarms`: до семи срабатываний на
  каждый будильник и не больше пятидесяти на все, чтобы повторы пережили
  несколько дней без запуска приложения
- перепланирование из корня навигации: при запуске, при возврате из фона, по
  `BOOT_COMPLETED`, при переводе часов и смене пояса, при любой правке
- экраны: список с ближайшим срабатыванием у каждой записи, экран правки,
  плашки на каждое недостающее разрешение
- время выбирается циферблатом на обычных `View`: числа — настоящие кнопки,
  протяжка сверху, кольцо часов с переключателем половины суток ради зон
  нажатия в 48 dp
- дата разового будильника выбирается месячной сеткой, прошедшие дни выключены
- будильник ставится из карточки дня: дата, время за час до смены и её
  название подставлены, запись уходит в общий список
- хранилище: версия схемы 4, будильники стали списком

Проверено: 90 тестов домена (17 на будильник), `tsc --noEmit` чистый, 66 проверок
контраста палитры, `expo-doctor` 21/21, автолинковка находит модуль, бандл
собирается. `expo-doctor` в прошлый раз поймал важное: правило `android/` в
`.gitignore` съедало нативную часть модуля — в сборку она бы не уехала. Теперь
`/android/`.

Не проверено ничего из нативного: Kotlin локально не компилируется, JDK и
Android SDK нет. Компиляция, слияние манифестов, само срабатывание, звук, выбор
мелодии, экран поверх блокировки и восстановление после перезагрузки
проверяются только сборкой APK и телефоном.

## 5. Доводка

- проход с включённым TalkBack и с максимальным размером шрифта
- проверка на переходе через полночь, на границе месяца и в ночь перевода часов
- production-сборка APK, установка вместо dev build

## Что осознанно вне работы

- публикация в маркет — не планируется
- синхронизация между устройствами и любой сервер — данные живут только на телефоне
- iOS — задача про Android
- производственный календарь с праздниками и переносами — точка расширения
  описана в [движке графиков](schedule-engine.md), но в план не входит
- учёт сверхурочных по трудовому кодексу и налогов — приложение считает то, что
  внёс пользователь, и ничего не начисляет само
